# Distillation-Column
• Optimized distillation column by predicting ethanol conc. from key input parameters to improve product quality.
• Trained Linear Regression (LR) and Support Vector Regression (SVR) models on a dataset with 5k+ entries.
• Achieved R2 of 0.9499 (MAE 0.0103) with LR, significantly outperforming SVR (R2 0.2968).
